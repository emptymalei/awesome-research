# Contributing

Thanks for helping researchers find good tools. There are two ways to add one.

## Option 1: open a pull request here

1. Search the list first, so the tool isn't added twice.
2. Add the tool under the section where a researcher would look for it.
3. Use one line per tool, in this format:

   ```markdown
   * [Tool Name](https://link.to/tool): One sentence on what it does for research.
   ```

4. Use `*` for list items and link to the tool's own site, not a review or an affiliate page.
5. Add one tool per pull request if you can. It makes review much faster.

## Option 2: use the form on tools.kausalflow.com

The list also lives at [tools.kausalflow.com](https://tools.kausalflow.com/), which has a page for every tool with features, fields, platforms and pricing.
You can [submit a tool there](https://tools.kausalflow.com/submit/) without a GitHub account.
Each submission is checked and opened as a pull request on [kausalflow/tools](https://github.com/kausalflow/tools), where you can follow its review.

## What gets accepted

- Tools that help with research work: reading, writing, data, code, collaboration, publishing, organising.
- Open-source and free tools are especially welcome. Paid tools are fine if they are genuinely useful to researchers.
- Pages made only for ranking or promotion are not accepted.
- Dead links are removed. If you find one, please open an issue or a pull request.
